Kernel type was not properly defined, due to missing #![engine(..)] attribute, or providing an invalid engine

Erroneous code example:

```compile_fail,E0798
// missing engine attribute!!

#[kernel]
unsafe fn gpu64(mut a: Buffer<i32>) {
}
```

To fix: 
```
#![engine(cuda::engine)]

#[kernel]
unsafe fn gpu64(mut a: Buffer<i32>) {
}
```
